# 安装与首次录制

第一次安装？可以先看[让 ZCode / Codex / WorkBuddy 帮你安装](AGENT-INSTALL.md)，复制首页指令让 Agent 准备文件。

## 下载插件

从仓库的 **Releases → Latest** 下载 `vibe-iter-chrome.zip`。解压到固定目录，在 Chrome 116+ 打开 `chrome://extensions`，启用开发者模式，选择「加载已解压的扩展程序」。选择的目录里必须直接包含 `manifest.json`。

普通 ZIP 不能拖进去直接安装。这个发行方式不需要签名密钥，也不是 Chrome Web Store 安装。

## 首次使用

1. 固定扩展图标，打开要测试的 HTTP/HTTPS 网页。
2. 打开 Vibe Iter 侧栏，点击「麦克风授权与设备测试」，允许麦克风并说话检查音量条。5 秒转录测试需要可选 Whisper 服务，单独授权和录制不需要。
3. 回到测试页，填入项目名称并开始。等待「录音已验证」、音频大小增长、音量条随说话变化，再正式试玩。
4. 正常操作和说话；侧栏可以关闭。按 `Ctrl+Shift+Y` 或重新打开侧栏结束。
5. 播放原音并导出 ZIP。没有启动转录服务时，也能完整保存录音与交互。

macOS 默认快捷键是 `Control+Shift+Y`；可在 `chrome://extensions/shortcuts` 修改。

## 自动转录

按 README 的 Python 步骤安装依赖和模型后，运行 `python scripts/transcription_server.py` 并保持终端运行。Windows 也可以在安装 Node.js 后用 `npm run voice` 启动后台服务。服务地址为 `http://127.0.0.1:4318/health`。

可用环境变量 `VIBE_WHISPER_MODEL` 选择另一个已缓存的模型。没有缓存时服务会报错，不会自动下载模型。转录可能慢于录音长度；关闭侧栏不会终止本机已提交的任务。

## 升级

先结束当前录制并导出重要记录，再用新文件替换原扩展目录。在扩展管理页点击刷新，刷新测试网页，然后重新打开侧栏。保持同一加载目录，避免产生另一份扩展身份和独立存储。

## 常见问题

| 情况 | 处理 |
| --- | --- |
| 「录音已保存，转录未完成」 | 先播放原音，启动本机服务后点击「转录整场 / 重试」 |
| 麦克风无法授权 | 检查 Chrome 网站权限、系统输入设备和系统麦克风权限 |
| 无法在页面开始 | Chrome 内部页、商店页不允许注入；切换到普通 HTTP/HTTPS 测试页 |
| 「侧栏与录音后台版本不一致」 | 刷新扩展、网页和侧栏，确认版本一致 |
| 没有语音文字 | 不代表没有录音；检查播放器和音频大小，转录后再导出 |
| 没有截图 | 确保原测试页是所在窗口的活动标签页 |

卸载扩展会删除浏览器中的历史。删除本机 Whisper 的 `.local/` 数据不会替你删除已导出的副本。
