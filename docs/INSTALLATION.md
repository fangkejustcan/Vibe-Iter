# 安装与首次录制

不想手动安装？把[首页的一句话](../README.md#让-agent-帮你安装)发给 ZCode / Codex / WorkBuddy，其余交给 Agent。

## 下载插件

从仓库的 **Releases → Latest** 下载 `vibe-iter-chrome.zip`。解压到固定目录，在 Chrome 116+ 打开 `chrome://extensions`，启用开发者模式，选择「加载已解压的扩展程序」。选择的目录里必须直接包含 `manifest.json`。

普通 ZIP 不能拖进去直接安装。这个发行方式不需要签名密钥，也不是 Chrome Web Store 安装。

## 首次使用

1. 固定扩展图标，打开要测试的 HTTP/HTTPS 网页。
2. 打开 Vibe Iter 侧栏，点击「麦克风授权与设备测试」，允许麦克风并说话检查音量条。5 秒转录测试需要可选 Whisper 服务，单独授权和录制不需要。
3. 回到测试页，填入项目名称并开始。等待「录音已验证」、音频大小增长、音量条随说话变化，再正式试玩。
4. 正常操作和说话；侧栏可以关闭。按 `Ctrl+Shift+Y` 或重新打开侧栏结束。
5. 播放原音，点击「保存反馈 ZIP」，文件自动进入 Chrome 下载目录下的 `Vibe-Iter` 文件夹。保存完成后点击「复制交接提示词」，发到对应项目 / worktree 的 Agent 对话。没有启动转录服务时，也能完整保存录音与交互。

侧栏显示测试页 URL、端口、录制时间和实际文件地址。文件名包含项目名、主机、端口、页面路径、导出时间和唯一标识，重复导出不会覆盖旧包。URL 来自本场录制，导出时切换标签页不会改变归属；每场历史记录保留自己的导出地址。若 Chrome 开启「下载前询问每个文件的保存位置」，浏览器仍可能要求确认；要自动保存可在 `chrome://settings/downloads` 关闭该选项，插件不会更改浏览器全局设置。

可在录制前展开「项目 / worktree 路径」填写实际工作目录，帮助 Agent 区分同一项目的不同 worktree。提示词要求先核对当前对话任务与工作目录；URL / 端口不同或无法确认归属时，暂停修改并提醒用户找到正确会话。相同端口可能被复用，不能单凭相同端口就认定匹配。

这次反馈应作为一次完整迭代综合完成并统一验证。插件只保存文件和复制提示词，不自动向任何 Agent 发消息。「更多导出方式」保留 ZIP 另存为、Markdown 和 JSON。Chrome 下载失败、取消、文件已删除或下载记录无法核实时，不提供可复制的交接提示词，重新保存后再试。

macOS 默认快捷键是 `Control+Shift+Y`；可在 `chrome://extensions/shortcuts` 修改。

## 可选：本机语音转文字

需要 Python 3.10+。在项目源码目录执行以下命令；macOS / Linux 若没有 `python`，改用 `python3`。推荐使用独立虚拟环境。

```bash
python -m pip install -r scripts/requirements-voice.txt
python -c "from faster_whisper import WhisperModel; WhisperModel('small', device='cpu', compute_type='int8')"
python scripts/transcription_server.py
```

首次下载模型需要网络；之后使用本机缓存。保持服务运行，检查 `http://127.0.0.1:4318/health` 返回 `ready: true`，再在侧栏点「转录整场 / 重试」。Windows 也可以在安装 Node.js 后用 `npm run voice` 启动后台服务。

可用环境变量 `VIBE_WHISPER_MODEL` 选择另一个已缓存的模型。没有缓存时服务会报错，不会自动下载模型。转录可能慢于录音长度；关闭侧栏不会终止本机已提交的任务。

## 升级

先结束当前录制并导出重要记录，再用新文件替换原扩展目录。在扩展管理页点击刷新，刷新测试网页，然后重新打开侧栏。保持同一加载目录，避免产生另一份扩展身份和独立存储。

## 常见问题

| 情况 | 处理 |
| --- | --- |
| 「录音已保存，转录未完成」 | 先播放原音，启动本机服务后点击「转录整场 / 重试」 |
| 麦克风无法授权 | 检查 Chrome 网站权限、系统输入设备和系统麦克风权限 |
| 无法在页面开始 | Chrome 内部页、商店页不允许注入；切换到普通 HTTP/HTTPS 测试页 |
| 「侧栏与录音后台版本不一致」 | 刷新扩展、网页和侧栏，确认版本一致 |
| 没有语音文字 | 不代表没有录音；检查播放器和音频大小，转录后再导出 |
| 没有截图 | 确保原测试页是所在窗口的活动标签页 |

卸载扩展会删除浏览器中的历史。删除本机 Whisper 的 `.local/` 数据不会替你删除已导出的副本。
