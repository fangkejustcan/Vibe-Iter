## 让 Agent 帮你安装

复制这句话，发给 **ZCode / Codex / WorkBuddy**：

```text
请读取 https://raw.githubusercontent.com/fangkejustcan/Vibe-Iter/main/docs/AGENT-INSTALL.md，帮我安装并开始使用 Vibe Iter。
```

其余交给 Agent；需要 Chrome 确认时，它会带你完成。

[直接下载插件](https://github.com/fangkejustcan/Vibe-Iter/releases/latest/download/vibe-iter-chrome.zip) · [手动安装](docs/INSTALLATION.md)

## 边玩边说，交给 AI 迭代

**开始测试 → 自然说出意见、操作网页 → 结束测试 → 导出 ZIP 交给 Agent。**

- **留下原声。** 持续录制麦克风，侧栏关闭后继续保存。
- **知道你指的是「哪个」。** 关联鼠标目标、操作时间线与采样截图。
- **把反馈带回代码。** 一份 ZIP 保留录音、操作、截图和已有转录，交给 Agent 分析并修改项目。

录音、播放与导出无需服务器。语音转文字使用可选的[本机 Whisper 服务](docs/INSTALLATION.md#可选本机语音转文字)。

数据保存在本机。记录可能包含页面文字、URL、输入和截图，分享前请检查；[隐私说明](PRIVACY.md)与[使用须知](docs/USER-NOTES.md)列出了采集范围和限制。
