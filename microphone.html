没有弹出授权提示，或之前点了拒绝？

打开 Chrome 设置 → 隐私和安全 → 网站设置 → 麦克风，在“不允许使用麦克风”的列表里移除 Vibe Iter，然后回来重试。也请检查 Windows 设置 → 隐私和安全性 → 麦克风，允许桌面应用访问，并确认 Chrome 使用了正确的输入设备。

默认使用本机 Whisper，录音和转录不发送到云端。本机服务未启动时，在项目目录运行 npm run voice。录音保存在项目的 .local/voice-clips 目录。
